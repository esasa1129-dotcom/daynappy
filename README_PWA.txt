デイナッピー PWA版（インストール用）

【大事】
デザイン本体は v2.49 完成版のままです。
今回変更したのは、ホーム画面へインストールするためのPWA設定だけです。

【使い方】
1. このZIPを解凍します。
2. 解凍したフォルダ一式を、HTTPSで公開できるWebサーバーへ置きます。
   ※ content:// や file:// で直接開いた状態では、PWAとしてのインストール機能は動きません。
3. AndroidのChromeで公開URLを開きます。
4. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
5. ホーム画面に「デイナッピー」のアイコンが追加されます。
6. 以後、そのアイコンから単独アプリ画面で起動できます。

【同梱】

その他、デイナッピー本体画像

【データについて】
予定データは端末のブラウザ内ストレージに保存されます。
今のローカルHTMLで登録したデータと、HTTPSで公開したPWA側のデータは別の保存領域です。
移行するときは、現在の設定画面からJSONを書き出して、PWA側で読み込む方法が安全です。
